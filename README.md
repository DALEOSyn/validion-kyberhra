# Kancelária STOPA

A short, free browser game in Slovak that teaches children aged 11–15 to recognise online scams and to respond
safely, for VALIDION's cybersecurity awareness programme. Two tracks, chosen on the start screen:
**Kancelária STOPA** (junior, 11–12, warm comic detective club) and **Ozvena** (teen, 13–15, investigation desk).
Each case takes about 5 minutes: read the brief, scan the evidence for clues, choose what to do, verify, practise,
and close the case file with the one rule and "Ak sa to už stalo".

The player only ever defends. All brands, apps, people and addresses in the game are fictional. The game sends
nothing anywhere: no accounts, no analytics, no network calls; progress lives in `localStorage` on the device.
See `CLAUDE.md` for the Red Lines.

## Run it

Requires Node 22.

```
npm ci
npm run dev         # local dev server
npm run build       # production build in dist/ (validates content first)
npm run typecheck   # TypeScript, strict
npm run lint        # ESLint
npm test            # Vitest: content schema + cross-references, scoring, progress, red-line rules
npm run redline     # red-line linter over content/
npm run validate    # content schema check only
npm run e2e         # Playwright smoke play-through + axe (uses installed Chromium; runs with --trace off)
```

The build is a static site (`dist/`) with relative paths, a web app manifest and a service worker that precaches
only the game's own files, so the game works offline after the first visit. Fonts (Baloo 2, Nunito, Special Elite,
SIL Open Font License) are bundled from `@fontsource`; nothing is loaded from a CDN.

## Add a case

1. Read `docs/CONTENT_SCHEMA.md` (fields, a complete example, the linter rules) and the case's spec in `docs/CASE_SPECS.md`.
2. Write `content/cases/<junior|teen>/<id>.yaml`. Cite source ids from `content/sources.yaml`.
3. Add `<id>` to the `cases:` list of the track in `content/tracks.yaml`. Its position is the case number.
4. Run `npm run validate && npm run redline && npm test`, then play it with `npm run dev`.

Speakers come from the track's `cast` in `tracks.yaml`. The help screen is `content/help.yaml`.

## Layout

```
content/            tracks.yaml, cases/<track>/<id>.yaml, sources.yaml, help.yaml
src/content/        schema.ts (Zod, build-time only), content.ts (typed runtime import)
src/engine/         pure logic: flow.ts (stages, lock-up), scoring.ts (stars, ranks), progress.ts (localStorage)
src/ui/             Preact screens and components
src/styles/         tokens.css (two themes), app.css, fonts.css (generated by scripts/build-fonts.ts)
scripts/            redline-lint.ts, redline-denylist.txt, validate-content.ts, lib/ (content loader, linter, sw)
tests/unit/         Vitest
tests/e2e/          Playwright
prototypes/         the approved HTML prototypes
```
